# Kurumi FX — 久留美 FX 模拟器 🦞💰

> 看了《FX战士久留美》后上头了，顺手搞的纯娱乐玩具。
> **虚拟资金，纯数字游戏，不构成任何投资建议。**

## 这是什么

一个外汇保证金交易的**体验模拟器**：给你一笔虚拟资金，可以加杠杆、交易、看行情、体会爆仓的痛。

灵感来源：番剧 **《FX战士久留美》**（FX戦士くるみちゃん）——讲述女大学生久留美被 FX 杠杆交易的暴利吸引入场，在保证金、汇率波动与人性的贪婪中反复挣扎的故事。一部把"金融风险"演成恐怖片的劝退神作。

看完第一反应：这玩意儿看着好刺激，我也想玩——但我不想真亏钱。
于是：为什么不做个假的呢？

## 功能

- [ ] 虚拟账户：初始资金 + 杠杆调节
- [ ] 模拟行情：随机游走 / 历史数据回放
- [ ] 交易系统：买入卖出、持仓、保证金、爆仓判定
- [ ] 破产结算：亏到爆仓显示"久留美脸"（待定）
