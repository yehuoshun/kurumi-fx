# Kurumi FX — 久留美 FX 模拟器 🦞💰

> 看了《FX战士久留美》后上头了，顺手搞的纯娱乐玩具。
> **虚拟资金，纯数字游戏，不构成任何投资建议。**

## 这是什么

一个外汇保证金交易的**体验模拟器**：给你一笔虚拟资金，可以加杠杆、交易各国"货币"、看行情、体会爆仓的痛。

灵感来源：番剧 **《FX战士久留美》**（FX戦士くるみちゃん）——讲述女大学生久留美被 FX 杠杆交易的暴利吸引入场，在保证金、汇率波动与人性的贪婪中反复挣扎的故事。一部把"金融风险"演成恐怖片的劝退神作。

看完第一反应：这玩意儿看着好刺激，我也想玩——但我不想真亏钱。
于是：为什么不做个假的呢？

## 货币体系（游戏世界观套壳）

**基准货币：久久币（JJB）** —— 向久留美致敬，玩家初始持有 30 万久久币（久留美开局数字），所有交易以久久币结算。

各国"货币"实为游戏世界观的戏仿（加国家 = 改配置表加一行）：

| 国家/地区 | 主城 | 货币 | 代码 | 央行（梗） |

| 提瓦特 | 蒙德 / 璃月港 | 摩拉 | MOR | 北国银行 |
| 今州 | 今州城 | 贝币 | SHE | 今州商会 |
| 塔卫二 | 终末地基地 | 塔卫币 | TAL | 终末地工业 |

> 塔卫币为占位名，待确认《明日方舟：终末地》官方货币后替换。

## 功能

- **行情引擎**：均值回归随机游走 + 5 档盘口模拟 + 大单价格冲击
- **交易系统**：市价/限价委托、吃对手盘撮合、滑点模拟、挂单冻结
- **杠杆**：1× / 2× / 5× / 10× / 50× / ∞（无限），购买力 = 现金 × 杠杆
- **融资负债**：余额透支即负债，净值 = 现金 + 持仓市值 − 负债
- **强制平仓**：净值耗尽自动全平，爆仓结算弹窗 + 红屏
- **客户经理「久留美」**：实时话术诱导 + 「独家/内幕/急报/猛料」消息流 + **一键同意**（∞ 杠杆满仓，随后行情闪崩）——听经理的，必爆仓
- **战绩**：成交笔数、净值曲线、最大回撤
- **存档**：localStorage 自动持久化

## 快速开始

```bash
# 无需安装依赖，起个静态服务器即可
python3 -m http.server 8777 --directory .
# 打开 http://localhost:8777/
```

跑引擎测试（Node 环境）：

```bash
node test.js   # 预期输出：18 通过 / 0 失败
```

## 技术架构

```
├── engine.js    # 核心引擎（纯逻辑，无 DOM）：行情/撮合/杠杆/强平/久留美
├── test.js      # 引擎冒烟测试（node test.js）
├── index.html   # 单页 UI（原生 JS + canvas，无构建）
├── README.md    # 本文件
└── LICENSE      # MIT
```

设计要点：
- `engine.js` 零依赖、无 DOM，可在 Node 直接单测
- 国家配置表集中在 `engine.js` 顶部 `COUNTRIES`，加国家只加一行
- 浏览器挂 `window`，Node 挂 `module.exports`，双环境同文件
